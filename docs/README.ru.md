# EasyRazer

Лёгкая замена Razer Synapse для Razer Huntsman V2 Analog (`1532:0266`) на Windows.
Точка нажатия каждой клавиши (1.5–3.6 мм) записывается в память клавиатуры,
после этого она работает без какого-либо запущенного софта.

**Неофициальный проект, не связан с Razer Inc.**

![Вкладка «Клавиши»: точки нажатия и Rapid Trigger](screenshots/actuation.png)

## Что умеет

- показывает и меняет точку нажатия каждой клавиши: «Применить» — до
  переподключения, «Записать» — в память клавиатуры (перед первой записью за
  сессию — бэкап в `%APPDATA%\EasyRazer`);
- профили: сколько угодно в программе, до пяти — в памяти клавиатуры; Fn+Menu — следующий;
- назначения клавиш: другая клавиша с модификаторами, кнопки мыши, медиа, отключение;
- Rapid Trigger по клавишам, с раздельной чувствительностью нажатия и отпускания
  (считает программа, пока она запущена);
- макросы: клавиши, мышь, паузы, запись нажатий;
- встроенные эффекты подсветки с живым предпросмотром и своя раскладка цветов по
  клавишам и зонам;
- переключатель динамического освещения Windows;
- работает из трея: запуск с Windows, сам возвращает настройки после
  переподключения, сна и выхода из Synapse;
- русский и английский интерфейс.

Подробно, с нюансами: [руководство пользователя](usage.md).

## Сравнение с Synapse

Замер на одном ПК: Synapse 4.0.827 сразу после запуска, EasyRazer 0.2.2 в трее в режиме HW.

| | Synapse 4 | EasyRazer |
|---|---|---|
| Стек | Electron (`RazerAppEngine`) и службы Windows | ядро на Rust, Tauri 2, интерфейс на Vue в системном WebView2 |
| Установка | установщик, ~1.2 ГБ на диске | один `.exe` на 8 МБ, без установщика |
| Процессы | 13: 11 × `RazerAppEngine`, Elevation Service, Game Manager Service | 7: `easyrazer` и 6 × WebView2 |
| Память, рабочий набор / private | ~1.75 ГБ / ~1.07 ГБ | ~385 МБ / ~235 МБ, из них сам `easyrazer` — 29 МБ / 8 МБ, остальное — WebView2 |
| Сеть | грузит модули устройств с `apps.razer.com` | не нужна |
| Кто определяет нажатия | всегда хост: Synapse ставит всем клавишам `0/0` и держит клавиатуру в driver mode | по умолчанию прошивка (HW); хост — только в режиме «Драйвер», ради Rapid Trigger |

### Режим HW

В HW клавиатура печатает сама, как без софта: хоста на пути ввода нет, лишней
задержки нет, падать нечему. В режим «Драйвер» EasyRazer переходит только ради
Rapid Trigger — аппаратного RT у Huntsman V2 Analog нет, Synapse тоже считает его на
хосте. При выходе, сбое и запуске Synapse EasyRazer возвращает клавиатуру в HW.

Цена: в HW прошивка ограничивает точку нажатия 1.62–3.56 мм, весь диапазон
1.5–3.6 мм — только в режиме «Драйвер».

### Износ flash

Ресурс MCU клавиатуры (STM32L4+) — 10 000 стираний страницы flash 4 КБ. Выравнивания
износа и счётчика стираний в прошивке нет, любая запись, даже 4 байта, стирает
страницу целиком. Поэтому EasyRazer:

- применяет изменения в оперативную память клавиатуры; во flash пишет только по
  явной команде («Записать», дискета), по желанию — с подтверждением;
- пишет слот профиля одной пачкой и только клавиши, которые отличаются от записанных;
- держит Rapid Trigger и свою раскладку цветов в программе, а не во flash.

Разбор прошивки: [firmware.md](firmware.md).

### Чего пока нет по сравнению с Synapse

Snap Tap, слой Hypershift, игровой режим и геймпад — см. дорожную карту.

## Synapse

Synapse держит клавиатуру в своём режиме и перезаписывает настройки.
Перед работой закройте его полностью, включая значок в трее.
Пока он запущен, EasyRazer ничего не пишет.

## Сборка

Нужны Rust (MSVC), Bun и MSVC Build Tools.

```
cd app
bun install
bun tauri dev      # запуск с пересборкой при изменениях
bun tauri build    # ..\target\release\easyrazer.exe
```

Готовый `easyrazer.exe` — один файл без установщика, его можно копировать куда угодно.

Тесты (из корня репозитория): `cargo test`, фронтенд: `bun run lint` (в `app`).
Тест на реальной клавиатуре (Synapse закрыт): `cargo test -p easyrazer -- --ignored`.
