# Прошивка Huntsman V2 Analog

Разбор официального Firmware Updater `v1.06.00` (прошивка `1.06.00`). Только
справка для протокола: код прошивки в проект не переносим. Адреса — для этой
версии. Выводы без прямой проверки помечены «вероятно».

## Где взять образ

Updater — .NET-программа. Образ лежит в `DeviceUpdater.resources` (распаковать
exe 7-Zip): строки `DevFWLine0..N` — записи Intel HEX по порядку номеров.
Там же параметры:

| Ключ | Значение |
|---|---|
| `VID` / `PID` | `1532` / `0266` |
| `BLPID` / `BLVER` | `110E` / `2.0` — загрузчик |
| `DevFWVer` / `FlashFWVer` | `1.06.00` / `1.02.00` |
| `FeatureReportLen` | `91` |

Образ не зашифрован и не сжат: `0x08007000`–`0x0801D044`, 90 180 байт.

Разбор — Ghidra headless: `ARM:LE:32:Cortex`, raw binary с базой `0x08007000`,
плюс неинициализированные блоки RAM `0x20000000`, периферия `0x40000000`,
данные flash `0x08080000`.

## Микроконтроллер

Вероятно, STM32L4P5/L4Q5 (L4+, 1 МБ flash в двух банках, 320 КБ RAM):

- ADC `0x50040000`, GPIO `0x48000000`, DMAMUX `0x40020800`, UID `0x1FFF7590`,
  USB OTG FS `0x50000000` — раскладка L4/L4+;
- `RCC+0x58` (APB1ENR1) с битом PWREN, контроллер flash `0x40022000`;
- магия загрузчика пишется в `0x2004FFFC` — конец 320 КБ RAM; начальный стек
  `0x2000EC68`;
- флеш до `0x080FFFFF`, второй банк с `0x08080000`.

## Карта памяти

| Адрес | Что там |
|---|---|
| `0x08000000`–`0x08006FFF` | загрузчик (в образ не входит) |
| `0x08007000`–`0x0801D044` | прошивка |
| `0x0801A724` | версия прошивки, 4 байта (`00:81`, `00:87`) |
| `0x0801A728` / `0x0801AD75` | заводские значения блоков config / settings |
| `0x0801BA00`, `0x0801BA80` | вероятно, таблицы матрицы клавиш и мультиплексора датчиков |
| `0x08080000`–`0x0808FFFF` | вероятно, сохранённые config, settings, профили |
| `0x08090000`–`0x080FFFFF` | хранилище макросов, `0x70000` байт = `0x6FFF0` из `06:8E` + 16 |
| `0x20000070`–`0x2000007C` | состояние индикаторов класса `03` |
| `0x200000F0` | режим устройства (`00:04`) |
| `0x200000F4` | dirty-биты отложенного сохранения |
| `0x20000165` | флаг калибровки (`FE:20`) |
| `0x20002D5C` | config, `0x64D` байт: серийник, калибровка датчиков |
| `0x200033AC` | settings, `0x1E4` байт: активный профиль, частота опроса, общие настройки |
| `0x20003690` | буфер пакета управления (91 байт) |
| `0x20008000` | профиль 0 (RAM), структура `0xA9D` байт |
| `0x20008A9D` + p·`0xA9D` | профили 1–5 |

В профиле: назначения клавиш, `+0xA5E` флаг `02:07`, `+0xA5F` флаг `0F:06`,
`+0xA63` эффект подсветки (34 байта).

## Запуск и главный цикл

- Reset → стартовый код → `0x08013CF4`: инициализация периферии, загрузка
  config/settings/профилей, затем бесконечный цикл.
- В цикле, вероятно: опрос клавиш, пакет управления, проигрыватель макросов,
  подсветка, отложенная запись во flash.
- `settings+0x5D == 0xAA` — особый режим: переключается комбинацией клавиш,
  зажатой при подключении (`0x080116B0`, таблица `0x0801AF90`), и сохраняется.
  В нём главный цикл идёт другой веткой, классы `03`/`0F` игнорируются, подсветка
  — волна. Назначение не выяснено.

## Прерывания

Номера IRQ по таблице STM32L4:

| IRQ | Обработчик | Назначение |
|---|---|---|
| 11 | `0x080075D4` | DMA1 канал 1 |
| 18 | `0x080072D8` | ADC1/2 — опрос датчиков |
| 28 | `0x0800D620` | TIM2 |
| 31–34 | `0x0800BBBC`–`0x0800BBE0` | I2C1/I2C2 — вероятно, драйверы подсветки |
| 54 | `0x0800D62C` | TIM6 |
| 67 | `0x0800D0F4` | USB OTG FS |

## Канал управления

Диспетчер — `0x08015568`, вызывается из главного цикла, когда USB-обработчик
положил пакет в `0x20003690`:

- CRC входящего пакета **не проверяется**; для ответа считается XOR байтов 2..87.
- Класс (байт 6) → обработчик:

| Класс | Обработчик | Условие |
|---|---|---|
| `00` | `0x08014B8C` | — |
| `02` | `0x08014190` | — |
| `03` | `0x08014F84` | не в режиме `0xAA` |
| `05` | `0x08015620` | — |
| `06` | `0x08015178` | — |
| `0F` | `0x08014730` | не в режиме `0xAA` |
| `F0`, `FE` | `0x08015794` | только в режиме устройства `02` |

- Неизвестная команда → статус `05`, ошибка аргументов → `03`. Некоторые
  команды отвечают `05` и при ошибке аргументов (`06:0A`, `06:8A`).
- Статус `01` в конце меняется на `02`: команда без явного результата — «ok».

Команды — в [protocol.md](protocol.md#команды-по-прошивке).

## Сохранение во flash

Команды не пишут flash сами: `0x08017724(n)` ставит dirty-бит в `0x200000F4`
и заводит таймер (`0x67` тиков, для `n = 7` — `0xCB`), запись делает главный
цикл.

| n | Бит | Что сохраняется |
|---|---|---|
| 0 | `02` | config (серийник, калибровка) |
| 1 | `01` | settings |
| 2 | `04` | вероятно, профили |
| 4 | `08` | `00:0B 00` |
| 5 | `10` | — |
| 7 | `40` | — |

## Назначения клавиш

Проверка назначения — `0x08012EBC`: допустимые fnId и длина данных.

| fnId | Длина | fnId | Длина |
|---|---|---|---|
| `00`, `0C` | любая | `08`, `09`, `0B`, `11` | 1 |
| `01` | 1 | `0A` | 2 |
| `02` | 2 | `0D` | 4 |
| `03` | 3 | `0E` | 3 |
| `04`, `05` | 2 | `0F` | 2 |
| `06` | по `data[0]`: 1, 2, 4 → 1; 3 → 2; 5 → 5 | `07` | по `data[0]`: 1, 2, 4, 5 → 1; 3 → 2 |

`10` и больше `11` отклоняются. fwID → позиция в матрице (`row << 4 | col`) —
`0x080120D0`.

## Датчики и калибровка

- Сырые значения ADC клавиш — `0x080120B0`; пары калибровки (верх/низ, 16 бит)
  — в config, 12 байт на клавишу, 16 клавиш на ряд (`row·0xC0 + col·0xC`,
  поля `+0x33`, `+0x37`).
- Доступ снаружи — только через класс `FE` в режиме `02` (см. protocol.md).

## Макросы

Проигрыватель — `0x08013940`:

- состояние — слоты по 26 байт в RAM с `0x2000D4E8`: режим, счётчик повторов,
  счётчик задержки, указатель на текущее событие, оставшаяся длина;
- событие читается прямо из flash (5 байт в буфер на стеке, `0x0800F4F8`),
  только если указатель в `0x08090000`–`0x08100000`, иначе чтение пропускается;
- разбор события — таблица переходов на опкоды `0x00`–`0x15`, те же, что в
  [protocol.md](protocol.md#макросы).

Тела макросов в RAM не копируются: проиграть макрос не из flash прошивка не может.

Обработчик класса `06` — `0x08015178`; индекс хранилища — `0x08018AB8`.

## Загрузчик

`00:04 01`: запрет прерываний, `0xAAAAAAAA` в `0x2004FFFC`, `SYSRESETREQ`
(`AIRCR = 0x05FA0004`). Загрузчик видит магию и остаётся в режиме обновления
(`1532:110E`).

## USB и данные

- Конфигурационный дескриптор — `0x0801A69C`, 134 байта, 5 интерфейсов.
- HID report-дескрипторы — `0x0801A3B0`–`0x0801A52C`: мышь, consumer, vendor,
  клавиатура с report ID, NKRO, LampArray (`05 59`).
- Строки: `Razer`, `Razer Huntsman V2 Analog`, `HID Config`, `HID Interface`.

## Не разобрано

Формат записей во flash `0x08080000`, формат индекса макросов, USB-стек
(`0x0800D0F4`), алгоритм актуации и поток глубины, драйверы подсветки по I2C,
назначение режима `0xAA`, загрузчик (в образ не входит).
