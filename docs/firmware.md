# Прошивка Huntsman V2 Analog

Разбор официального Firmware Updater `v1.06.00` (прошивка `1.06.00`). Только
справка для протокола: код прошивки в проект не переносим. Адреса — для этой
версии. Выводы без прямой проверки помечены «вероятно».

## Где взять образ

Updater — .NET-программа. Образ лежит в `DeviceUpdater.resources` (распаковать
exe 7-Zip): строки `DevFWLine0..N` — записи Intel HEX по порядку номеров.
Там же параметры:

| Ключ | Значение |
|---|---|
| `VID` / `PID` | `1532` / `0266` |
| `BLPID` / `BLVER` | `110E` / `2.0` — загрузчик |
| `DevFWVer` / `FlashFWVer` | `1.06.00` / `1.02.00` |
| `FeatureReportLen` | `91` |

Образ не зашифрован и не сжат: `0x08007000`–`0x0801D044`, 90 180 байт.

Режим `01` (`00:04 01`) перезагружает клавиатуру в загрузчик `1532:110E`.

## Микроконтроллер

Вероятно, STM32F1 XL-density или совместимый GD32F30x:

- Cortex-M, flash с `0x08000000`, адреса в коде — до `0x080FFFFF` (1 МБ, два
  банка по 512 КБ);
- RCC `0x40021000`, контроллер flash `0x40022000`, TIM8 `0x40013400`,
  DMA1/DMA2 `0x40020000`/`0x40020400`, I2C1/I2C2 `0x40005400`/`0x40005800`;
- начальный стек `0x2000EC68` — RAM около 60 КБ.

## Карта flash

| Адрес | Что там |
|---|---|
| `0x08000000`–`0x08006FFF` | загрузчик (в образ не входит) |
| `0x08007000`–`0x0801D044` | прошивка |
| `0x08080000`–`0x0808FFFF` | вероятно, профили и назначения клавиш (`0x08080000`, `0x08081000` в коде) |
| `0x08090000`–`0x080FFFFF` | хранилище макросов, `0x70000` байт = `0x6FFF0` из `06:8E` + 16 |

## Прерывания

Используются (номер IRQ по таблице STM32F1): 11 DMA1 канал 1, 18 ADC1/2 —
вероятно, опрос датчиков клавиш, 28 TIM2, 31–34 I2C1/I2C2 — вероятно, драйверы
подсветки, 54 TIM6.

## Макросы

Проигрыватель — `0x08013940`:

- состояние — слоты по 26 байт в RAM с `0x2000D4E8`: режим, счётчик повторов,
  счётчик задержки, указатель на текущее событие, оставшаяся длина;
- событие читается прямо из flash (5 байт в буфер на стеке, `0x0800F4F8`),
  только если указатель в `0x08090000`–`0x08100000`, иначе чтение пропускается;
- разбор события — таблица переходов на опкоды `0x00`–`0x15`, те же, что в
  [protocol.md](protocol.md#макросы).

Тела макросов в RAM не копируются: проиграть макрос не из flash прошивка не может.

## USB и данные

- Конфигурационный дескриптор — `0x0801A69C`, 134 байта, 5 интерфейсов.
- HID report-дескрипторы — `0x0801A3B0`–`0x0801A52C`: мышь, consumer, vendor,
  клавиатура с report ID, NKRO, LampArray (`05 59`).
- Строки: `Razer`, `Razer Huntsman V2 Analog`, `HID Config`, `HID Interface`.
- Вероятно, таблицы раскладки и трансляции кодов клавиш — около `0x0801BA00`–
  `0x0801BCB4`.

## Не разобрано

Обработчик команд канала управления (MI_03), опрос датчиков и калибровка,
подсветка, профили во flash, загрузчик.
