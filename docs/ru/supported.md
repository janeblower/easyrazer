## Huntsman V2 Analog

Поддерживается, проверено на железе. Rapid Trigger и Snap Tap считает программа
(режим «Драйвер»); часть режимов макросов не проверена.

## Huntsman Mini Analog

V2 Analog в формате 60%: тот же код прошивки и протокол, поэтому поддержка как у
V2 Analog, проверенной на железе, — надёжнее линейки V3. На самой этой клавиатуре не
проверялось, хотя проблем быть не должно. Пока не проверено: в оперативную память
клавиатуры пишет только с разрешением в настройках, в её память — нет, поэтому макросов
и слотов профилей нет; эффекта подсветки custom нет.

## Huntsman V3 Pro

В разработке, на железе не проверено. По умолчанию только чтение; с разрешением в
настройках пишет в оперативную память клавиатуры, в её память — нет. В HW режиме
Rapid Trigger и одну пару Snap Tap считает прошивка. Нужен тестер с клавиатурой.

## Huntsman V3 Pro TKL

Как V3 Pro, без нампада и PrtSc / ScrLk / Pause; версия 8 kHz такая же. Без эффекта
подсветки custom.

## Huntsman V3 Pro Mini

Проверено на железе ([#45](https://github.com/janeblower/easyrazer/issues/45), прошивка 2.00):
точка нажатия, Rapid Trigger и Snap Tap в режимах HW и «Драйвер», эффекты подсветки и
яркость. Запись по-прежнему только в оперативную память клавиатуры, с разрешением в
настройках. Переход в режим «Драйвер» делает стартовым профиль 1, и он таким остаётся.
Имена профилей пока не читаются; без эффекта подсветки custom.

## Huntsman V3 TKL 8KHz

Как V3 Pro, с полной картой TKL на 87 клавиш; без эффекта подсветки custom и без
Windows Dynamic Lighting. Прошивка — отдельная кодовая база, поэтому уверенности меньше,
чем для моделей V3 Pro.

## Huntsman V3 Pro 8KHz

Как V3 Pro.

## Huntsman Signature Edition

Как V3 Pro TKL.

## Huntsman V3 Pro Low-profile TKL 8KHz

Как V3 Pro TKL, с точкой нажатия до 2.8 мм: низкопрофильные переключатели мельче.
Без Windows Dynamic Lighting. Прошивка — кодовая база V3 TKL 8KHz.

Протокол и прошивка каждой модели — в [devices](devices/README.md).

## Помогите проверить свою модель

Есть одна из моделей 🧪? Запустите EasyRazer, включите в настройках «Писать в
клавиатуры, не проверенные на железе», попробуйте функции из таблицы и
[создайте issue](https://github.com/janeblower/easyrazer/issues): что работает, а что нет.
Запись идёт только в оперативную память клавиатуры, переподключение её отменяет.
