# Протокол Huntsman V3 Pro TKL

На железе не проверено. По прошивке 1.04.00 ([firmware.md](firmware.md)) протокол —
как у [V3 Pro](../huntsman-v3-pro/protocol.md): те же HID-интерфейсы, управление на
интерфейсе 3, пороги u16, Rapid Trigger и Snap Tap в прошивке, поток глубины в
отчёте `0B`. У TKL 8 kHz (`02D0`) всё так же.

## Отличия

- PID `02A7`; у версии 8 kHz — `02D0`.
- Клавиатура без нампада: матрица датчиков 7 × 14, 84 клавиши в ANSI. Нет нампада
  и PrtSc / ScrLk / Pause.
- Размер матрицы подсветки неизвестен, поэтому эффект custom не предлагается.
