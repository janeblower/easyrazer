# Прошивка Huntsman Mini Analog

Разбор официального Firmware Updater (прошивка `1.03.00`). Справка по протоколу: код
прошивки в проект не переносится. Адреса — для этой версии. Прошивка собрана из того же
кода, что у V2 Analog ([прошивка V2 Analog](../huntsman-v2-analog/firmware.md)); здесь
только проверенное и отличия.

## Образ

`DeviceUpdater.resources`:

| Ключ | Значение |
|---|---|
| `VID` / `PID` | `1532` / `0282` |
| `BLPID` / `BLVER` | `110E` / `2.0` |
| `DevFWVer` | `1.03.00` |
| `FlashFWUpdate` | `0`: второго чипа нет |

`DevFWLine0..5179` — Intel HEX, `0x08007000`–`0x0801B373`, 82 804 байта, без
шифрования. Как у V2 Analog, загрузчик занимает `0x08000000`–`0x08006FFF`.

## Как у V2 Analog

- USB: 5 интерфейсов с теми же HID-дескрипторами (61, 212, 79, 22, 327 байт),
  дескриптор конфигурации — `0x0801936C`; управление — feature report 90 байт, поток
  глубины — отчёт `07`.
- Ограничение порогов: хвост функции по `0x08016D4C` побайтно совпадает с V2:
  срабатывание `15..250`, отпускание не меньше `5` и не больше срабатывания − 10.

Набор тот же, что в матрице V3 Pro Mini: 61 клавиша ANSI с Esc (`110`) на месте
тильды, остальное — клавиши ISO/JIS.

## Не разобрано

- Диспетчер классов, набор команд и формат профилей: считаем такими же, как у
  V2 Analog.
- Размер матрицы подсветки.
