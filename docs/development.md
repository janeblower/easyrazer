# Разработка

## Окружение

Windows 11, Rust (`stable-x86_64-pc-windows-msvc`), MSVC Build Tools, Bun.
Сборка и запуск — в [README](README.ru.md#сборка).

Тесты:

```
cargo test                          # ядро и приложение, из корня
cargo test -p easyrazer -- --ignored  # на живой клавиатуре, Synapse закрыт
cd app && bun run lint              # фронтенд
```

Ядро тестируется на фейке клавиатуры `crates/core/src/fake.rs`: он понимает
команды актуации, эффектов и `0F:03`. Новая команда в ядре — сначала в фейк.

## Структура

| Путь | Что там |
|---|---|
| `crates/core` | Протокол Razer без зависимостей от ОС; `hidapi` — за фичей `hid` |
| `crates/core/devices/*.json` | Описания моделей: PID, интерфейс управления, набор эффектов |
| `crates/core/protocols/*.json` | Системы команд подсветки и шаблоны байтов эффектов |
| `crates/core/src/keymap.rs` | Имена клавиш → `fwID` |
| `crates/core/src/layout.rs` | Геометрия клавиш для карты и ячейки сетки подсветки |
| `crates/core/src/analog.rs`, `actuation.rs` | Назначение клавиши `02:12`/`02:92`, чтение и запись порогов |
| `crates/core/src/profiles.rs` | Слоты `05:xx`, снимок профиля, дифф и запись одной пачкой |
| `crates/core/src/rapid.rs` | Движок RT: разбор потока глубины, пороги, автоповтор, Fn-слой |
| `crates/core/src/lighting.rs` | Кодирование эффектов из шаблонов протокола |
| `crates/probe` | `razer-probe` — CLI для исследования протокола |
| `app/src-tauri` | Tauri 2: устройство, фоновый поток, трей, автозапуск, движок на Windows (`engine.rs`) |
| `app/src-tauri/src/profiles.rs` | Профили программы над слотами: импорт, загрузка в профиль 0, управление |
| `app/src` | Vue: вкладки, карта клавиатуры, локали `locales/*.json` (общие с Rust) |

Протокол и всё найденное на железе — [protocol.md](protocol.md).

## Правила

- **Flash изнашивается.** Во flash пишем только по явной команде пользователя
  («Записать», дискета) и пакетом. Живые изменения — во временную память
  (профиль `0`).
- **Synapse запущен — ничего не пишем.**
- **Код Razer не копировать.** Бандлы Synapse — только справка по протоколу.
- **Каркас не раздувать:** трейт или новый крейт появляются со второй реализацией
  (вторая модель, вторая ОС).
- Новые тексты — в обе локали, `ru.json` и `en.json`.

## Новая модель клавиатуры

Описание-данными сделано только для подсветки. Остальное пока привязано к
Huntsman V2 Analog, и вторая модель — повод вынести это в описание.

1. **Разведка.** `razer-probe list` — HID-интерфейсы; управляющий — feature report
   91 байт (у V2 Analog — MI_03). `razer-probe info` — прошивка и режим.
   `razer-probe get …` — read-only команды. PID в `crates/probe/src/main.rs` зашит,
   поменять на время разведки.
2. **`crates/core/devices/<vid>-<pid>.json`** — имя, `vid`, `pid`,
   `control_interface`, `tid` (transaction id), `lighting.protocol` и `led`,
   список поддерживаемых эффектов, `lamp_array` (если есть HID LampArray).
   Добавить файл в `DEVICES` в `crates/core/src/devices.rs`.
3. **Протокол подсветки.** Если команды или байты эффектов другие — новый
   `protocols/<name>.json` и строка в `PROTOCOLS`. Шаблон эффекта — байты после
   `profile led` с подстановками `{rgb1}`, `{rgb2}`, `{dir}`, `{speed}`.
4. **Раскладка и `fwID`** — `keymap.rs` и `layout.rs` сейчас одни на всех. Для
   другой раскладки их придётся сделать частью описания модели.
5. **Аналог.** Формула порога (`analog.rs`: 0..255 ↔ 1.5..3.6 мм), команды `02:12`/
   `02:92`, коллекции потока глубины (MI_01 Col06/Col04 в `app/src-tauri/src/engine.rs`)
   и таблица scancode там же — всё под V2 Analog. У V3-моделей актуация и RT —
   отдельные onboard-команды `02:19`/`02:1A` (см. protocol.md), движок на хосте им
   не нужен.
6. Фейк в `fake.rs`, если модель отвечает иначе; тест `--ignored` на железе.

Неизвестная клавиатура Razer в окне — «Модель не поддерживается (PID …)».

## Новый эффект подсветки

Шаблон в `protocols/*.json` → имя в `effects` модели → тексты
`lighting.groups`/`types` в локалях. Интерфейс собирает параметры (цвета,
направление, скорость) из шаблона сам.

## Где искать дальше

Для Snap Tap, макросов, биндов и игрового режима понадобится снова читать Synapse:

- бандлы логики устройства кешируются в
  `%LOCALAPPDATA%\Razer\RazerAppEngine\User Data\Default\Service Worker\CacheStorage\…`
  (URL `apps.razer.com/synapse/products/614/`): `rzDevice25.*.js` — сеттеры и
  геттеры, `3159.*.js` — таблица аналоговых команд, `6737.*.js` — middleware
  (профили, OBM, конвертация UI → FW);
- логи — `%LOCALAPPDATA%\Razer\RazerAppEngine\User Data\Logs\products_614_*.log`
  (строка `appEngine value` показывает, что Synapse отдаёт своему движку);
- хостовый движок Synapse — `CommonDLL\mapping_engine.dll`.

## Известные мелочи

- Окно подвисает на кнопке закрытия, пока идёт чтение актуации.
- `reg.exe` вызывается в основном потоке из меню трея.
- Повторный запуск с `--tray` показывает окно запущенной копии.
- Автозапуск ссылается на старый путь после переноса exe.
- Рамка выделения захватывает огранку, если начата у края карты.
- Подсветка: «Применить» без клавиатуры не проверяет эффект; черновик теряется при
  переподключении; один битый параметр сбрасывает весь `settings.json`.
- RT: при жёстком убийстве процесса клавиатура молчит до переподключения.
